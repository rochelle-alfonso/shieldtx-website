# ShieldTX website

Static marketing site for ShieldTX — plain HTML, CSS and JavaScript, no build step.

- `index.html` — page markup
- `styles.css` — layout and type
- `hero-shader.js` — WebGL2 dithered background: hero shield, scroll zoom, ambient field and the step graphics (wallet, shield, wallet stack, bar chart)
- `intro-scroll.js` — pinned hero and zoom into the shield
- `steps-scroll.js` — pinned Fund / Shield / Create / Execute stepper
- `text-reveal.js` — headline and copy entrances

Run locally with any static server, e.g. `python3 -m http.server 8777`.
